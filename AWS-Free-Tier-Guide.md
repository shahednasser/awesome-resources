# Beginner's Guide to AWS Free Tier

## 1. Sign Up
- Go to [AWS Free Tier](https://aws.amazon.com/free/)
- Create a free account with your email
- Verify your account using credit card (no charges for free tier usage)

## 2. Key Free Tier Services
- **EC2:** Run a small virtual server (t2.micro) for free
- **S3:** Store up to 5GB for free
- **Lambda:** Run code without provisioning servers, 1M free requests per month
- **RDS:** 750 hours of db.t2.micro per month

## 3. Tips for Beginners
- Always monitor your usage to avoid charges
- Use the AWS Free Tier calculator to estimate usage
- Start with simple projects like hosting a static website
